# Farm Equipment Maintenance (PWA)

Offline-first installable web app. React + Vite, data stored in IndexedDB on the device.

## Commands
- `npm install` – download the building blocks (once)
- `npm run dev` – run on your computer for development
- `npm run build` – make the production version in `dist/`
- `npm run preview` – serve the production version locally

## Milestone 1 (done)
Add / edit / list / delete machines with photo, filter part numbers, fluid types and capacities.

## Phone testing
Installing a PWA needs HTTPS. The included GitHub Actions workflow publishes the app to
GitHub Pages at `https://<your-username>.github.io/farmapp/`.
